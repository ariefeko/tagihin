# Tagihin - Laundry Billing & Customer Management System

Tagihin adalah aplikasi manajemen billing laundry yang dibangun dengan fokus pada kecepatan pengembangan dan performa tinggi menggunakan ekosistem Laravel modern.

## Tech Stack (TALL Stack)

- **Tailwind CSS:** Untuk desain UI yang modern dan responsif.
- **Alpine.js:** Untuk interaktivitas frontend yang ringan.
- **Laravel 11:** Sebagai core framework dengan PHP 8.4.
- **Livewire:** Untuk membangun antarmuka dinamis tanpa meninggalkan ekosistem Laravel.
  
---

## Fitur Unggulan

- **Seamless Interaction:** UI yang reaktif tanpa perlu manajemen API yang kompleks.
- **Billing Logic:** Sistem kalkulasi otomatis untuk berbagai layanan laundry.
- **Customer Management:** Database pelanggan terpusat dengan riwayat pesanan lengkap.

---

## Cara Menjalankan

1. Clone repo.
2. `./vendor/bin/sail up -d`
3. `composer install` & `npm install`
4. `php artisan migrate`
